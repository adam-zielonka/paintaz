Using this version

A current browser with WebAssembly and WebGL is required. Files stay in browser memory; no images are uploaded to a server. Open uses your browser's file picker; Save and Save As each request a new PNG download. The browser controls its name/location; neither action promises to overwrite an existing local file. Download before leaving or reloading: there is no autosave.

Import: PNG, JPEG and BMP. TIFF is not included in this build (convert it to PNG first). Up to 4096 pixels per side and 4,194,304 pixels total; encoded imports are limited to 32 MiB. Undo snapshots also consume memory. Text uses Qt's bundled font, not your device fonts.

This is the shared desktop Qt Widgets interface. On a narrow screen use toolbar overflow menus and canvas scrollbars. Touch emulates the mouse; this is not a redesigned mobile drawing UI. Qt's browser accessibility and mobile support have limitations; see Qt platform notes.

Shortcuts: Ctrl+N new, Ctrl+O open, Ctrl+S download, Ctrl+Z undo, Ctrl+Y redo, 1 freehand, 2 line, 3 rectangle, 4 rounded rectangle, 5 ellipse. Brush → Full fills shapes.
